# Mokku UI Library

**Mokku UI Library** es una librería de componentes reutilizables basada en [Tailwind CSS](https://tailwindcss.com/) y [shadcn/ui](https://ui.shadcn.com/), pensada para acelerar el desarrollo de interfaces modernas y escalables en el ecosistema React y Next.js.

Cuenta con integración completa con **Storybook 8** para visualizar, documentar y testear los componentes de forma aislada.

---

## 🚀 Tecnologías utilizadas

- [Next.js](https://nextjs.org/) (como entorno base)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [shadcn/ui](https://ui.shadcn.com/)
- [Storybook](https://storybook.js.org/) v8
- [class-variance-authority (CVA)](https://cva.style/)
- [Prettier](https://prettier.io/) + ESLint
- [Rollup](https://rollupjs.org/) (opcional para empaquetar como librería)

---

## 📦 Instalación

```bash
git clone https://github.com/mokku/mokku-ui-library.git
cd mokku-ui-library
npm install
```

---

## 📦 Levantar la App

```bash
npm run storybook
```

Esto abre Storybook en http://localhost:6006, donde podrás:
Ver todos los componentes disponibles
Cambiar variantes y props desde el panel de controles
Visualizar ejemplos reales de uso con estilos aplicados
